Consistent help and exit codes

Now: Commands report errors in different ways.

Should: Every command supports --help, with usage and one example. Exit codes are 0 for OK, 1 for a validation error, 2 for a usage error and 3 for locked or in use. An unknown command suggests the closest command name.

Part 1: --help on every command.
Done when: A test runs --help on every command and checks for a usage line and an example.

Part 2: The exit codes.
Done when: A table-driven test covers at least one case of each code for every command that can produce it.

Part 3: The suggestion for unknown commands, by edit distance.
Done when: A test runs "ledger balanse" and gets "Did you mean: balance?" and exit code 2.

Every part's new test must fail on today's code and pass after the part.
Rules: Work only inside this project folder. Do not add, remove or update packages. Keep every existing test green and the full test run under 2 minutes. Throwaway scripts go in _scratch/, which git ignores; do not commit them.
