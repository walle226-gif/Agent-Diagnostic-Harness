=== C01 | 1 | edge | Local time and the October clock change
Now: Timestamps without an offset are stored as if they were UTC.
Should: Each source has a time zone (default Europe/Stockholm, using zoneinfo). Timestamps without an offset are converted to UTC. In the repeated hour on 2026-10-25 (02:00 to 03:00 happens twice), lines are given the first or second occurrence by their order in the file: when the clock goes backwards, switch to the second.
P: Converting local timestamps to UTC.
D: Tests cover a summer time, a winter time and a timestamp that already has an offset.
P: The repeated hour in October.
D: A test with a sample file running from 01:50 through the repeated hour to 03:10 gets strictly increasing UTC times.
P: The hour that does not exist in March (2026-03-29 02:30) counts as an invalid line, with a warning.
D: A test checks the warning count and that the line is not stored.

=== C02 | 1 | feature | Compressed and rotated files without duplicates
Now: Running ingest twice stores every line twice, and .gz files cannot be read.
Should: .gz files are read directly. The position in each file is remembered, so running ingest again only reads new lines. A rotated file (renamed, then a new file under the old name) is not read twice; it is recognised by a hash of its first line.
P: Reading .gz files.
D: A test ingests a gzipped sample and gets the same events as from the plain file.
P: Remembering the position per file.
D: A test ingests, appends three lines, ingests again and finds exactly three new events.
P: Recognising a rotated file.
D: A test renames the file, creates a new one under the old name, ingests both, and finds no duplicates.

=== C03 | 1 | feature | Error spikes per minute
Now: A burst of server errors is only found by reading the log.
Should: "logwatch analyze anomalies" counts 5xx responses per minute and compares each minute with the median and the median absolute deviation (MAD) of the previous 60 minutes. A minute is flagged when it is above median + 5 × MAD and has at least 5 errors. Flagged minutes go into an anomalies table and are listed.
P: Counting errors per minute.
D: A test checks the counts for a sample log, including minutes with no errors.
P: The detector as a pure function on a list of counts.
D: Tests with made-up series cover a flat series, a single spike and a slow rise that is not flagged.
P: The table and the CLI command.
D: A CLI test lists one flagged minute for a sample with one burst.
