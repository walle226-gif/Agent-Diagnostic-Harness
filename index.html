What it isVad det är

An agent that reads and edits files, runs commands and tests, and reports what actually happened. The model runs locally, for places where cloud assistants are not permitted, such as defence, healthcare, legal and industry.

The code it writes is yours, made on your machine by a model under the open Apache 2.0 licence. The tested setup fits one 16 GB card; larger cards run larger models.

En agent som läser och ändrar filer, kör kommandon och tester och rapporterar vad som faktiskt hände. Modellen körs lokalt, för miljöer där molnassistenter inte är tillåtna, som försvar, vård, juridik och industri.

Koden den skriver är er, skapad på er maskin av en modell under den öppna licensen Apache 2.0. Den testade uppsättningen ryms på ett 16 GB-kort; större kort kör större modeller.

Nothing runs unapprovedInget körs utan godkännande

Every file write, command and commit is approved first; a denied action is explained, not retried.

Varje filskrivning, kommando och incheckning godkänns först; ett nekat steg förklaras i stället för att försökas igen.

There is always a way backDet finns alltid en väg tillbaka

The project is snapshotted outside its folder before the first destructive action, and recursive deletes with a computed target are refused.

Projektet kopieras utanför sin mapp före första förstörande steget, och rekursiva raderingar med framräknat mål nekas.

Claims are checkedPåståenden kontrolleras

Code is compile-checked at once, tests that never import their module do not count, and the agent predicts each command's result first.

Kod kompileringskontrolleras direkt, tester som aldrig importerar sin modul räknas inte, och agenten förutsäger varje kommandos resultat först.

It runs what it buildsDen kör det den bygger

It runs and watches programs and types scripted input, catching bugs where unit tests pass but the program does nothing.

Den kör och iakttar program och matar in färdiga rader, och fångar fel där enhetstesterna går igenom men programmet inte gör någonting.

It tunes the machineDen trimmar maskinen

GPU memory per model is measured, not guessed: we measured a 13× spread that parameter counts do not predict, and settings follow from it.

Grafikminnet per modell mäts i stället för att gissas: vi mätte 13 gångers spridning, som antalet parametrar inte förutsäger, och inställningarna följer av det.

Proven work is saved instantlyBevisat arbete sparas direkt

A fix proven correct is copied automatically out of the agent's reach.

En lagning som bevisats korrekt kopieras automatiskt utom räckhåll för agenten.

Its reasoning is on recordDess resonemang sparas

Models chosen by measurementModeller väljs efter mätning

A small, fast model solved a hard bug that a model four times its size did not, so models are chosen by measurement.

En liten, snabb modell löste en svår bugg som en modell fyra gånger så stor inte klarade, så modeller väljs efter mätning.

How you write the task changes the workHur uppgiften skrivs ändrar arbetet

Removing one contradiction from a task halved the planning reply, on a second machine too, so the agent now asks about two measured kinds of self-contradicting request.

När en motsägelse togs bort ur en uppgift halverades planeringssvaret, även på en andra maskin, så agenten frågar nu om två uppmätta sorters motsägelsefulla beställningar.

Its own verification was auditedDess egen verifiering granskades

We audited every firing of the rule that reminds the agent to run its fixes, and rewrote it to look for a test of that specific edit.

Vi granskade varje utlösning av regeln som påminner agenten om att köra sina lagningar, och skrev om den så att den letar efter ett test av just den ändringen.

Existing code costs moreBefintlig kod kostar mer

The same requirements cost 3.5× more in existing code than in an empty folder, because the work avoids the old code; the benchmark now includes such tasks.

Samma krav kostar 3,5 gånger mer i befintlig kod än i en tom mapp, eftersom arbetet undviker den gamla koden; testunderlaget innehåller nu sådana uppgifter.

The tooling is measured tooVerktygen mäts också

Much lost time was in the tooling, not the model; each such case becomes a fixed defect with a test.

Mycket tid förlorades i verktygen, inte i modellen; varje sådant fall blir ett åtgärdat fel med ett test.

Den behöver en modellserver på maskinen eller i nätverket, till exempel ett 16 GB-grafikkort; medvetet finns ingen reservväg till molnet.
