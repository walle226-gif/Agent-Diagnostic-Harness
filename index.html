What it isVad det är

An agent that reads and edits your code, runs commands and tests, and reports what actually happened. Built for places where cloud assistants are not permitted, such as Defence, Healthcare, Legal and Industry.

En agent som läser och ändrar er kod, kör kommandon och tester och rapporterar vad som faktiskt hände. Byggd för miljöer där molnassistenter inte är tillåtna, som Försvar, Vård, Juridik och Industri.

Nothing leaves your networkInget lämnar ert nätverk

The model runs on your own hardware. No code, keys or prompts are sent anywhere, and there is no cloud fallback.

Modellen körs på er egen hårdvara. Ingen kod, inga nycklar och inga frågor skickas någonstans, och det finns ingen reservväg till molnet.

Works while you are out of officeArbetar när ni är borta från kontoret

Leave a list of work orders before you go: at the end of the day, before a weekend or a holiday. Each step is tested and saved on its own, and a report waits when you are back.

Lämna en lista med arbetsorder innan ni går: efter arbetsdagen, inför en helg eller en semester. Varje steg testas och sparas för sig, och en rapport väntar när ni är tillbaka.

Every claim is checkedVarje påstående kontrolleras

The project's own tests run after every step, and a separate referee runs the finished code. A claim the tools cannot back up does not count.

Projektets egna tester körs efter varje steg, och en separat domare kör den färdiga koden. Ett påstående som verktygen inte kan styrka räknas inte.

Safe by defaultSäker från början

Anything outside the project, or that cannot be undone, asks a person first. There is always a saved state to go back to.

Allt utanför projektet, eller som inte går att ångra, frågar en människa först. Det finns alltid ett sparat läge att gå tillbaka till.

Grows with your teamVäxer med teamet

Start on one 16 GB card for one developer. Move the model to a shared 48, 72 or 96 GB server, and the same agent serves up to 20 people.

Börja på ett 16 GB-kort för en utvecklare. Flytta modellen till en delad server med 48, 72 eller 96 GB, så räcker samma agent till upp till 20 personer.

Yours to keepEr att behålla

The code it writes is yours, made by an open model under the Apache 2.0 licence. Fixed prices and no usage limits.

Koden den skriver är er, skapad av en öppen modell under licensen Apache 2.0. Fasta priser och inga användningsgränser.

Good to know. It runs a smaller model than the cloud services, so it is slower, and it does best with work you can describe in clear steps. Measured so far on C#, TypeScript, Python, Go and JavaScript: web applications, business systems, services and desktop tools. C, C++ and embedded code are not yet measured, so a pilot measures it on your own code first. More under Stated plainly.

Bra att veta. Den kör en mindre modell än molntjänsterna, så den är långsammare, och den gör bäst ifrån sig med arbete som går att beskriva i tydliga steg. Hittills uppmätt på C#, TypeScript, Python, Go och JavaScript: webbapplikationer, affärssystem, tjänster och skrivbordsverktyg. C, C++ och inbyggd kod är ännu inte uppmätta, så en pilot mäter den på er egen kod först. Mer under Sagt rakt ut.

What happens when something goes wrongVad som händer när något går fel
  • An order fails its tests. Its work is set aside under the order's name, the project goes back to the last saved state, and the next order starts.
  • It asks for permission and nobody answers. It is never answered for you; after ten minutes the order waits for you and the next one starts.
  • You step in. A message or Stop takes over at once and pauses the list.
  • Every order starts clean: nothing unsaved and all tests passing, so one order cannot break the next.
  • En order klarar inte testerna. Arbetet läggs undan under orderns namn, projektet går tillbaka till det senast sparade läget och nästa order börjar.
  • Den ber om tillstånd och ingen svarar. Den får aldrig ett svar i ditt ställe; efter tio minuter väntar ordern på dig och nästa börjar.
  • Du kliver in. Ett meddelande eller Stopp tar över direkt och pausar listan.
  • Varje order börjar rent: inget osparat och alla tester gröna, så en order kan inte förstöra nästa.

Stated plainly. Tests show that the work runs, not that it is what you had in mind; you read the result in the morning. Two of the eight orders stopped to wait for a person, and the night exposed a fault of ours (a changed file left out of the saved history), now corrected.

Sagt rakt ut. Testerna visar att arbetet fungerar, inte att det är det du tänkte dig; du läser resultatet på morgonen. Två av de åtta orderna stannade och väntade på en människa, och natten avslöjade ett eget fel (en ändrad fil kom inte med i den sparade historiken), som nu är rättat.

Safety and checksSäkerhet och kontroller

Built on one rule: nothing gets to misreport, not the agent, the tests, the instruments or us.

Byggd på en enda regel: ingenting får rapportera fel, varken agenten, testerna, mätverktygen eller vi.

Nothing risky runs unapprovedInget riskabelt körs utan godkännande

Anything that reaches outside the project or cannot be undone, such as mail or desktop control, always asks first. You choose whether ordinary changes inside the project also ask.

Allt som når utanför projektet eller inte går att ångra, som e-post eller skrivbordsstyrning, frågar alltid först. Ni väljer själva om vanliga ändringar inne i projektet också ska fråga.

There is always a way backDet finns alltid en väg tillbaka

The project is snapshotted outside its folder before the first destructive action, and recursive deletes with a computed target are refused.

Projektet kopieras utanför sin mapp före första förstörande steget, och rekursiva raderingar med framräknat mål nekas.

Claims are checkedPåståenden kontrolleras

Code is compile-checked at once, tests that never import their module do not count, and a separate referee runs the finished code against answers fixed in advance.

Kod kompileringskontrolleras direkt, tester som aldrig importerar sin modul räknas inte, och en separat domare kör den färdiga koden mot facit som bestämts i förväg.

It runs what it buildsDen kör det den bygger

It runs and watches programs and types scripted input, catching bugs where unit tests pass but the program does nothing.

Den kör och iakttar program och matar in färdiga rader, och fångar fel där enhetstesterna går igenom men programmet inte gör någonting.
