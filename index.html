What it isVad det är

An agent that reads and edits files, runs commands and tests, and reports what actually happened. The model runs on your own hardware, for places where cloud assistants are not permitted, such as defence, healthcare, legal and industry.

The code it writes is yours, made by an open model under the Apache 2.0 licence, on one 16 GB card or a shared server.

En agent som läser och ändrar filer, kör kommandon och tester och rapporterar vad som faktiskt hände. Modellen körs på er egen hårdvara, för miljöer där molnassistenter inte är tillåtna, som försvar, vård, juridik och industri.

Koden den skriver är er, skapad av en öppen modell under licensen Apache 2.0, på ett 16 GB-kort eller en delad server.

What happens when something goes wrongVad som händer när något går fel

  • An order fails its tests. Its work is set aside under the order's name, the project goes back to the last saved state, and the next order starts.
  • It asks for permission and nobody answers. It is never answered for you; after ten minutes the order waits for you and the next one starts.
  • You step in. A message or Stop takes over at once and pauses the list.
  • Every order starts clean: nothing unsaved and all tests passing, so one order cannot break the next.
  • En order klarar inte testerna. Arbetet läggs undan under orderns namn, projektet går tillbaka till det senast sparade läget och nästa order börjar.
  • Den ber om tillstånd och ingen svarar. Den får aldrig ett svar i ditt ställe; efter tio minuter väntar ordern på dig och nästa börjar.
  • Du kliver in. Ett meddelande eller Stopp tar över direkt och pausar listan.
  • Varje order börjar rent: inget osparat och alla tester gröna, så en order kan inte förstöra nästa.

Stated plainly. Tests show that the work runs, not that it is what you had in mind; you read the result in the morning. Two of the eight orders stopped to wait for a person, and the night exposed a fault of ours (a changed file left out of the saved history), now corrected.

Sagt rakt ut. Testerna visar att arbetet fungerar, inte att det är det du tänkte dig; du läser resultatet på morgonen. Två av de åtta orderna stannade och väntade på en människa, och natten avslöjade ett eget fel (en ändrad fil kom inte med i den sparade historiken), som nu är rättat.

Safety and checksSäkerhet och kontroller

Nothing risky runs unapprovedInget riskabelt körs utan godkännande

Anything that reaches outside the project or cannot be undone, such as mail or desktop control, always asks first. You choose whether ordinary changes inside the project also ask.

Allt som når utanför projektet eller inte går att ångra, som e-post eller skrivbordsstyrning, frågar alltid först. Ni väljer själva om vanliga ändringar inne i projektet också ska fråga.

There is always a way backDet finns alltid en väg tillbaka

The project is snapshotted outside its folder before the first destructive action, and recursive deletes with a computed target are refused.

Projektet kopieras utanför sin mapp före första förstörande steget, och rekursiva raderingar med framräknat mål nekas.

Claims are checkedPåståenden kontrolleras

Code is compile-checked at once, tests that never import their module do not count, and a separate referee runs the finished code against answers fixed in advance.

Kod kompileringskontrolleras direkt, tester som aldrig importerar sin modul räknas inte, och en separat domare kör den färdiga koden mot facit som bestämts i förväg.

It runs what it buildsDen kör det den bygger

It runs and watches programs and types scripted input, catching bugs where unit tests pass but the program does nothing.

Den kör och iakttar program och matar in färdiga rader, och fångar fel där enhetstesterna går igenom men programmet inte gör någonting.

Behind it: 355 fast tests, 2,481 mutation anchors that catch faked test success, 428 logged findings and 117 pre-registered studies. Requires local hostingKräver lokal modell

It needs a model server on the machine or network, such as a 16 GB GPU; there is no cloud fallback, by design.

Den behöver en modellserver på maskinen eller i nätverket, till exempel ett 16 GB-grafikkort; medvetet finns ingen reservväg till molnet.

Windows-firstWindows i första hand

Developed and measured on Windows; other platforms are not yet tested.

Utvecklad och uppmätt på Windows; andra plattformar är ännu inte testade.

Unattended within the project, never beyond itSjälv i projektet, aldrig utanför

It can work through a list of orders alone, but anything outside the project or that cannot be undone waits for a person; if nobody answers, that order waits and the next one starts. Not for unattended changes to running production systems.

Den kan arbeta sig igenom en lista med order på egen hand, men allt utanför projektet och allt som inte går att ångra väntar på en människa; om ingen svarar får den ordern vänta och nästa börjar. Inte för obevakade ändringar i system som är i drift.

One model, measured deeplyEn modell, djupt uppmätt
