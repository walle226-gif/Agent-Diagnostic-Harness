# Agent Diagnostic & Reasoning Harness

An empirical benchmarking framework designed to isolate, measure, and analyze LLM agent reasoning traps, code-attention fixation, and diagnostic loops during multi-turn debugging.

## Core Capabilities
* **State-Verification Gates:** Deterministic execution locks and byte-identical trace assertion validation.
* **Reasoning Budget Circuit Breakers:** Real-time token telemetry to intercept and break runaway context loops.
* **Reproducible Testbeds:** Isolated diagnostic cells for testing tool mechanics across open-weights and proprietary model architectures.
